KEY FUNCTIONS:
===============
1. openTab(evt, tabName)
   - Navigates between 4 tabs per lesson
   - Called by tab button onclick="openTab(event, 'tab1')"

2. flipCard(el)
   - Flips vocabulary cards to reveal definitions
   - Smooth CSS transitions

3. startTimer() / resetTimer()
   - 5-minute countdown timer
   - Visual warnings at 30 seconds and 10 seconds
   - Click-to-start design (no auto-start)

4. Answer Reveals
   - onclick="var a=this.nextElementSibling; a.classList.toggle('show')..."
   - Toggle display with smooth visibility transitions
   - Dynamic button text (Show/Hide Answer)
