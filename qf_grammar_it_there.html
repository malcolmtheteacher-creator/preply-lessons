📍 Quick Fix: It Is vs There Is

Use there is/are to introduce something new; use it is to refer back

Level: A2/B1

What's wrong here?

Is cold today.

Is cold today.

English ALWAYS needs a subject. This should be:

It is cold today.

The confusion: IT IS vs THERE IS/ARE

IT IS

  • Weather: "It's raining." / "It's hot."
  • Time: "It's 3 o'clock." / "It's Monday."
  • Distance: "It's 5km away."
  • Referring back to something: "That film was great. It was amazing."

THERE IS / THERE ARE

  • Introducing existence: "There is a problem." / "There are many people here."
  • Asking about availability: "Is there a café nearby?" / "Are there any seats?"
  • Describing what's in a place: "There was a long queue." / "There are two doors."

CRITICAL RULE

English NEVER drops the subject. You MUST have either it or there at the beginning:

Is raining. ✗

It is raining. ✓

Fix It

See the difference between IT IS and THERE IS/ARE. Then rewrite the sentences below.

IT IS

⛅

Weather: "It's hot"

Time: "It's noon"

Distance: "It's 5km"

Reference: "It was great"

THERE IS/ARE

🏪

Existence: "There is a café"

Availability: "There are no seats"

Introduction: "There was a problem"

What's in a place: "There are 2 doors"

Rewrite these sentences:

1. "Is very hot in this room."

2. "It is many restaurants in this city."

3. "Is a great film — you should watch it."

4. "It was a long queue at the station."

Produce

Write a sentence for each prompt. Choose IT IS or THERE IS/ARE correctly.

1. Talk about the weather — it's very windy.

2. Say a park exists nearby.

3. Say the distance to the airport is 20km.

4. Say there are no tickets left.
