It is vs There is

Master the difference: specificity vs. existence

Can You Spot the Difference?

Mistake 1: Introducing Something New

❌ Wrong
It is a cat in the garden.
✓ Correct
There is a cat in the garden.
The cat is new information. We use there is to introduce something that exists somewhere.

Mistake 2: Describing Weather/Temperature

❌ Wrong
There is cold today.
✓ Correct
It is cold today.
Weather and temperature use it is. "It" is impersonal — we're not talking about a specific thing.

Mistake 3: Talking About Time

❌ Wrong
There is late.
✓ Correct
It is late.
Time expressions use it is — like weather, time is impersonal and abstract.

Mistake 4: Too Many Things

❌ Wrong
It are many people here.
✓ Correct
There are many people here.
When introducing multiple things, use there are (not "there is"). Notice the verb changes to match the plural noun.

When to Use Each

IT IS
  • Weather: It is sunny / It is raining / It is cold
  • Time: It is 3 o'clock / It is late
  • Distance: It is 10 km away
  • Referring back: "A ghost appeared" → "It was scary"
  • Describing: It is beautiful / It is difficult
THERE IS / ARE
  • Introducing: There is a pen on the desk
  • Existence: There are 5 students in the class
  • Location unknown: There is a problem
  • First mention: There is a girl waiting for you
  • Plural: There are many reasons
The key difference: Use IT IS when you're talking about something specific or describing a condition. Use THERE IS/ARE when you're introducing something that exists, especially for the first time.

Practice: Choose the Right One

Write Your Own Sentences

Read each situation and write a correct sentence. Use "It is" or "There is/are" as needed.

Situation 1: You're looking out the window. It's raining and cold outside. Write a sentence about the weather.
Situation 2: Someone asks you if there are students in the classroom. Confirm that yes, there are students. Write the sentence.
Situation 3: You're explaining why you can't go to the meeting. There are several reasons (too busy, don't have transport, feeling sick). Write a sentence introducing these reasons.
Situation 4: A friend ate spicy food and is now uncomfortable. Describe what the temperature is like in their mouth right now.
