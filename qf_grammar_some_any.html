Know when to use each | A2 Level

✓ Correction

Do you have any questions?

📌 The Rule

SOME = positive sentences and offers/requests

ANY = questions and negative sentences

Exception: In polite offers/requests, use SOME: "Would you like some coffee?" or "Can I have some help?"

📚 The Rule (Dual Coding)

✅ SOME (Positive)

😊

I have some ideas.

She ate some pizza.

Would you like some tea?

Positive statements, offers, requests

❓ ANY (Questions/Negatives)

❌

Do you have any money?

I don't have any friends.

There isn't any milk.

Questions and negative sentences

💡 Bonus: Polite offers = use SOME! "Can I get you some coffee?" or "Would you like some help?"
