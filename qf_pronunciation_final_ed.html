-ED Ending Pronunciation

A2 • Universal • Three sounds: /t/ /d/ /ɪd/

🔍 Let's notice what we hear

Listen to this common mistake:

❌ "I walk-ED to the store" (saying it like an extra syllable)

Should be: "I walked to the store" (walk + /t/ sound, same syllable)

But sometimes -ED IS a new syllable:

✓ "I want-ED" (two syllables: WANT-id)

✓ "I need-ED" (two syllables: NEED-id)

Why? When does -ED become an extra syllable? What's the rule?

🎯 The Rule:

The -ED has THREE different pronunciations, depending on the sound BEFORE it:

🔵 /t/ after voiceless sounds (p, k, f, s, sh, ch, x)

🟢 /d/ after voiced sounds (b, g, v, z, l, m, n, r, vowels)

🟠 /ɪd/ (new syllable!) after /t/ and /d/ sounds

🛠️ Three pronunciations of -ED

🔵 /t/ VOICELESS

/t/
After voiceless sounds:
• p (stop → stopped)
• k (walk → walked)
• f (laugh → laughed)
• s (miss → missed)
• sh (push → pushed)
• ch (watch → watched)
• x (mix → mixed)
Examples: walked, stopped, watched, laughed, missed

🟢 /d/ VOICED

/d/
After voiced sounds:
• b (rub → rubbed)
• g (hug → hugged)
• v (love → loved)
• z (use → used)
• l (play → played)
• m (blame → blamed)
• n (open → opened)
• r (arrive → arrived)
• vowels (stay → stayed)
Examples: played, opened, arrived, loved, hugged

🟠 /ɪd/ NEW SYLLABLE

/ɪd/
After /t/ or /d/:
• t → wanted, started
• d → needed, decided
Examples (2 syllables): want-ed, need-ed, paint-ed, start-ed
💡 The trick:

Say the word WITHOUT -ed first. If it ends in a VOICELESS sound (p, k, f, s, sh, ch), add /t/. If it ends in a VOICED sound (b, g, v, z, l, m, n, r, vowel), add /d/. If it ends in /t/ or /d/, add /ɪd/ (new syllable).

✏️ Practice: SAY these words

/t/ Words (One syllable):

Say: walked (walk + /t/) → WAWKT

Say: stopped (stop + /t/) → STOPT

Say: watched (watch + /t/) → WATCHT

Say: missed (miss + /t/) → MISST

/d/ Words (One syllable):

Say: played (play + /d/) → PLAYD

Say: opened (open + /d/) → OH-pund

Say: lived (live + /d/) → LIVD

Say: closed (close + /d/) → KLOHZD

/ɪd/ Words (Two syllables — a new syllable!):

Say: wanted → WANT-ed (two syllables!)

Say: needed → NEED-ed (two syllables!)

Say: painted → PAINT-ed (two syllables!)

Say: decided → de-CIDE-ed (three syllables!)

Key points:

✓ walked = WAWKT (/t/)

✓ talked = TAWKT (/t/)

✓ laughed = LAFT (/t/)

All /d/ sounds → No extra syllable!

Key points:

✓ played = PLAYD (/d/)

✓ moved = MOOVD (/d/)

✓ lived = LIVD (/d/)

Say (3 times) — extra syllables!

"They wanted and needed to paint the house."

Two syllables each!

Key points:

✓ wanted = WANT-ed (2 syllables: /ɪd/)

✓ needed = NEED-ed (2 syllables: /ɪd/)

✓ paint = no -ed, just pronounced as is
