🔮 First Conditional Errors

Use present simple in the if-clause, not will | B1 Level

What do you notice?

Read this sentence. What feels wrong?

If it will rain, I will stay at home.

What needs to change — and why?

✓ Correction

If it rains, I will stay at home.

📌 The Rule

In first conditional sentences, the if-clause uses the present simple tense, not "will". The result clause (the main clause) uses will/can/might + infinitive.

Pattern: If + present simple, + will/can/might + infinitive

More examples:

  • If you study hard, you will pass. ✓ (NOT: "If you will study")
  • If she calls me, I will tell her. ✓ (NOT: "If she will call")
  • If we are late, they can start without us. ✓ (NOT: "If we will be")

📚 The Rule

❌ Wrong

🚫
If it will rain...
If she will call...
If we will be late...

✓ Correct

✅
If it rains...
If she calls...
If we are late...

Practice: Fix the errors

1. If you will study hard, you will pass.

2. If she will call me, I will tell her.

3. If we will be late, they will start without us.

4. If it will be sunny, we can go to the beach.
