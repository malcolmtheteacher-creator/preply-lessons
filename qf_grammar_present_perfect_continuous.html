✅ Present Perfect Simple vs Continuous

Master results and duration | B2 Level

What's the correction?

✓ Correction

I have read this book—it's great!

📌 The Rule

Present Perfect Simple = completed action, the RESULT matters

Example: "I've read it" = I finished it | "I've written 3 emails"

Present Perfect Continuous = ongoing/recent action, the DURATION matters

Example: "I've been reading for 2 hours" (still going or just stopped)

Simple = HOW MANY/MUCH. Continuous = HOW LONG

📚 The Rule (Dual Coding)

✅ SIMPLE

🏁 📊 ✔️

Result / Complete

I've written 3 emails

I've read the book

How many? How much?

⏱️ CONTINUOUS

⌚ 🔄 ⏸️

Duration / Ongoing

I've been reading for 2 hours

I've been sleeping since 9 PM

How long?
