One image, 24 small treasures in a 6 x 4 grid, painted in the same style as the rooms. I cut them out and put one in each alcove as the student finishes lessons.

How to use:
1. Open ChatGPT, attach one of the room images (the Study is best) so it copies the painting style and lighting, and paste the prompt below.
2. If it comes back with the wrong count, or objects touching, say: "Exactly 24 objects, 6 columns by 4 rows, each fully separate with magenta all round it."
3. Send me the image (or save it as `journey/img/objects.png`).
