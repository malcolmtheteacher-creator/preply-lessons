# My Room: painted room prompts

Six rooms, one per "chapter" of a student's journey. Each room has **eight empty arched alcoves** (four on each wall). The page puts the student's lesson objects *into* those alcoves in code, so the alcoves must be empty.

How to use:
1. Generate **Room 1 first** in ChatGPT (image generation). Pick the best result.
2. For rooms 2-6, upload Room 1 and add: *"Use the attached image as the exact reference for camera angle, scale, wall height, floor size, alcove size and spacing, and painterly style. Change only the room as described."* This keeps all six rooms matched.
3. Save as `journey/img/room1_study.webp` ... `room6_conservatory.webp` (1600 x 1000 is plenty; webp, around 250 KB).
4. Tell me when they are in. I'll switch the page to use them and we place the alcove hotspots together (an edit mode is built in).

## Shared style (already inside every prompt below)

Painted isometric cutaway diorama, like a collectible museum model. Warm golden-hour light, deep soft shadows, rich materials, a feeling of quiet and wonder. Plain very dark warm-black background (#14110f) so the page blends. 16:10 landscape. No text, no people, no objects in the alcoves, no frames, no logos.

## Why these prompts are built this way

- **Empty alcoves, same positions in every room** → the page can place the student's objects exactly, and the same hotspot layout works for all six rooms.
- **Fixed camera and scale** → the rooms feel like one palace as the student moves through them.
- **Dark neutral background** → the page blends into it.
- **A shared reference image from Room 1** → ChatGPT's biggest weakness is drift; this pins it down.
- **If an alcove is not empty or the count is wrong:** regenerate, saying "all eight alcoves must be completely empty, four on each wall".
