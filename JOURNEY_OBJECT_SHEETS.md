# My Room: painted object sheets

359 objects on 10 sheets, 36 per sheet (6 columns by 6 rows). Each lesson in My Room gets the object that matches its title.

How to use, once per sheet:
1. In ChatGPT, attach one room picture (the Study is best) so it copies the painting style, then paste the sheet prompt.
2. If the count or order is wrong, say: "Exactly 36 objects, 6 columns by 6 rows, in the order listed, each fully separate with magenta all round it." If ChatGPT struggles with 36, ask for the first 18 and then the last 18 as two images and tell me.
3. Save each result as `journey/img/sheet01.png` ... `sheet10.png` (or just send them to me). Tell me which sheet number each is.
