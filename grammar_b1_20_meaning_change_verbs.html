Stopping Something: "I stopped..." vs "I stopped to..."

Same verb, two very different meanings.

Spot the pattern

  • "I stopped checking my phone before bed — it was ruining my sleep."
  • "On the drive, we stopped to get petrol."
  • "Grandma stopped drinking coffee years ago."

Two of these mean the habit ended. One means someone paused to do something else. Which one, and why?

Check the pattern CLICK
Sentence 2 is the odd one out. stop + -ing = the habit or action ends (no more checking, no more coffee). stop + to + verb = you pause one activity in order to do something short and different (you stop driving to get petrol).
stop + -ing = end a habit or action
stop + to + verb = pause in order to do something else
"I was walking, then I paused to tie my shoe."
→
"I stopped to tie my shoe."

Remembering & Forgetting: Duty First or Memory After?

These verbs point in two different directions in time.

Spot the pattern

  • "Did you remember to lock the door?"
  • "I remember locking the door — I can picture turning the key."
  • "I forgot to call my sister yesterday, and now she's annoyed."

In sentence 1 and 3, does the memory come before the action, or after it? What about sentence 2?

Check the pattern CLICK
remember/forget + to + verb = the task comes after the memory in time — you either did the duty or you didn't (lock the door, call your sister). remember/forget + -ing = the action already happened, and now you're recalling it — the memory comes after the event.
remember/forget + to + verb = a duty (comes after the memory)
remember/forget + -ing = a memory of something already done (comes before)
"I had to buy milk. Did I do it?"
→
"Did I remember to buy milk?"
"Forget" can also take -ing, usually for something so vivid you couldn't forget it even if you tried: "I'll never forget seeing the northern lights." It's much rarer than "remember + -ing."

Trying, Continuing, and Getting Things Done

Three more verbs that shift meaning depending on what follows them.

Trying something

  • "The wifi's down — try restarting the router."
  • "I tried calling him three times, but no answer."
  • "It's a tough conversation, but try to stay calm."

Two of these are quick experiments — "let's see if this works." One is a real effort at something difficult. Which one?

Check the pattern CLICK
Sentence 3. try + -ing = experiment, see if it helps (restart the router, see what happens). try + to + verb = make a real effort at something hard, with no guarantee of success (staying calm in a tough conversation is genuinely difficult).
try + -ing = experiment, see if it helps
try + to + verb = make an effort at something difficult

Continuing — or moving on

  • "She went on talking for another twenty minutes."
  • "The rain went on falling all afternoon."
  • "After the coffee break, he went on to explain the new rules."

In two sentences, the same activity just keeps going. In one, the person finishes one thing and starts something new. Which one?

Check the pattern CLICK
Sentence 3. go on + -ing = keep doing the same thing (still talking, still raining). go on + to + verb = finish one thing, then move to something different next (finish the break, then start explaining).
go on + -ing = keep doing the same thing
go on + to + verb = finish, then do something different next

Getting something done

  • "The car needs servicing before the trip."
  • "This shirt needs ironing."
  • "You need to book a table — it gets busy on Fridays."

Two of these are about something being done to a thing (nobody says who). One is about a person actively doing something. Which one?

Check the pattern CLICK
Sentence 3. [thing] needs + -ing = someone must do something to it — same meaning as "needs to be done" (the car needs to be serviced). [person] needs + to + verb = the person themselves must actively do it.
[thing] needs + -ing = needs to be done to it
[person] needs + to + verb = the person must actively do it
"Someone needs to fix this bike."
→
"This bike needs fixing."
