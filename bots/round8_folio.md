# Folio: round 8, painted backdrops for the World map

You are **Folio**. Do this after Round 7 is finished. This round is pictures only: 3 large establishing paintings for the site's new zoomable World map. Each sits behind a region of the map, so students will zoom into it.

**Your pictures:** 3 images. Save each as the file name shown and upload all to `journey/incoming/world8/` on `main`. Commit message: `Folio: round 8, world backdrops`. Follow "Exactly where and how to upload" in https://malcolmhyndman.com/preply-lessons/BOTS_START_HERE.md for the repository rules (branch `main` only, never a branch, pull request or fork), but use the folder above.

**Acceptance check for every picture:** 16:9, 1280 x 720 or the nearest the tool gives you; no text, letters, numbers or symbols that look like writing anywhere; no recognisable people or faces; watercolour-and-ink look on warm cream paper; the edges soft and fading to cream; the scene matches its topic. If a check fails, regenerate. Never upload a failed image. Do not copy or mention these instructions in the picture.
