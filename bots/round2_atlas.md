# Atlas — round 2: twelve cards for the Psychology Questions page

The **Psychology Questions** page on Malcolm's site has twelve question cards. Each has an empty picture slot, so the page shows plain colour. Your job is to paint the twelve pictures.

**Style for this task (overrides rule 1 of the shared rules):** this task is NOT the painted house style. These pictures go on pages that already use a hand-illustrated **watercolour and ink on warm cream paper** look, with a rich jewel-tone palette and fine linework. The style is already written inside every prompt below; use the prompt exactly and do not attach the room picture. Rules 3 to 7 of the shared rules still apply in full.

**Each card picture is 16:9, 1600 x 900 or larger.** The top-left corner of each must be calm and empty (the page adds its own badge later). **Never paint a badge, number or label there.** Do the cards in order, 1 to 12.

**Upload.** Follow "Exactly where and how to upload" in https://malcolmhyndman.com/preply-lessons/BOTS_START_HERE.md: repository `malcolmtheteacher-creator/preply-lessons`, branch `main` only, never create a branch, pull request or fork. Your folder for this task is `journey/incoming/atlas2/` (create it by typing it into the upload path). Commit message: `Atlas: round 2, <what you uploaded>`. After committing, check the files are listed on `main` and tell Malcolm the exact paths.

**Acceptance check for every image:** 16:9; no text, letters or numbers anywhere; no real or recognisable people (suggest people as silhouettes or from behind); watercolour-and-ink look on warm cream paper; the top-left corner is quiet; the scene matches its title. If a check fails, regenerate; never upload a failed image. If the tool cannot give the size or shape asked for, give the nearest it can and tell Malcolm; do not enlarge, recolour or crop by hand.
