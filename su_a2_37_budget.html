Future Plans Language

These patterns help you talk about plans, promises, and wishes.

Plan + to infinitive

"We plan to lower taxes." = an intention

Hope + to infinitive

"We hope to make everyone feel richer." = a wish or dream

Will + base form

"We will cut government spending." = a promise or definite plan

Promise + to infinitive

"We promise to keep interest rates low." = a commitment

Want + to infinitive

"We want to reduce VAT." = a desire

Grammar Pattern

plan / hope / promise / want + to + infinitive

Gap-fill Practice

Complete the sentences with the correct verb form.

1. The government to build more hospitals.

Correct! We use "plan + to + infinitive".

2. We to improve public transport.

Correct! We use "hope + to + infinitive".

3. They reduce taxes next year.

Correct! We use "will + base form".

4. I to save more money this year.

Correct! Both "want + to + infinitive" and "promise + to + infinitive" work here.

5. The mayor to create more green spaces.

Correct! We use "promise + to + infinitive".
