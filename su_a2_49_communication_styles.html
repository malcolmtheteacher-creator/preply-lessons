Direct vs Indirect Communication

Direct Communication

  • Says exactly what they mean
  • Gets to the point quickly
  • Values honesty and clarity
"I don't agree with this plan."
Can seem: efficient, clear, but sometimes rude

Indirect Communication

  • Suggests rather than states
  • Takes time to build up to the point
  • Values harmony and politeness
"That's an interesting idea, but perhaps we could consider..."
Can seem: polite, diplomatic, but sometimes unclear

Remember: Neither style is better — they are just different.

Softening Language

When you want to be more indirect in English, you can use softening language:

Instead of: "You're wrong"
Better: "I see it differently"
Instead of: "No"
Better: "I'm not sure about that"
Instead of: "Do it now"
Better: "Would you mind doing it when you get a chance?"
Instead of: "That's a bad idea"
Better: "That's an interesting point, but have you considered...?"
Instead of: "I don't understand"
Better: "Could you explain that in a different way?"
Instead of: "You need to change this"
Better: "Perhaps we could look at this from another angle"
Useful softening words: perhaps, maybe, I think, it seems, would you mind, could we

Time and Culture

Different cultures experience time differently:

Fixed Time (Monochronic)

  • One task at a time
  • Meetings start and end on time
  • Deadlines are very important
  • Being late = rude

Flexible Time (Polychronic)

  • Multiple tasks at once
  • Meetings can start late
  • Relationships more important than schedules
  • Being late = sometimes acceptable

Where are you on this scale?

Very Fixed Balanced Very Flexible

Working With Different Time Styles

💡 If someone has FIXED time preferences:
Be on time. Send agendas. Set clear deadlines.
💡 If someone has FLEXIBLE time preferences:
Be patient. Build relationships first. Allow extra time.
