Discussion Notes

The First Conditional

Pattern

If + present simple, will + infinitive

We use the first conditional to talk about things that are possible or likely in the future.

Example Sentences

If we move to cheaper offices, we'll save money.

We'll be able to choose better offices if we move.

If we reduce staff, people will be unhappy.

Sales will improve if we invest in advertising.

Important Note

The 'if' part can come first or second. When it comes first, use a comma.
