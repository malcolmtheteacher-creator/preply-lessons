# Mia's English — Art Checklist (for ChatGPT → gitsite)

**How to use:** generate each image in ChatGPT, then save it into the `gitsite` folder with the **exact filename in bold**. Make the 3 character sheets FIRST — they're your references. Every prompt below is self-contained (the style is baked in), so it works even without the project brief.

Total: **3 character sheets + 12 scenes = 15 images.**
