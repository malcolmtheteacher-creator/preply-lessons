❓ Quick Fix: Question Tags

Positive statement → negative tag / Negative statement → positive tag

What's wrong here?

She's coming, isn't it?

isn't it — The tag doesn't match the subject!

The pronoun in the tag must match the subject of the main clause.

The Rule

Positive statement → negative tag

Example: "You're tired, aren't you?"

Negative statement → positive tag

Example: "She didn't come, did she?"

The tag uses:

  • The same auxiliary/modal as the main clause
  • A pronoun matching the subject
  • The opposite polarity (positive → negative or vice versa)

No auxiliary in main clause? Use do/does/did

Correct version:

She's coming, isn't she?

Understanding the Pattern

POSITIVE statement

✅ → ❌

Negative tag

You like it,
don't you?

NEGATIVE statement

❌ → ✅

Positive tag

You don't like it,
do you?

Common Tag Patterns

Main Clause Tag Example
I am... aren't I? I am next, aren't I?
You/We/They are... aren't you/we/they? You're tired, aren't you?
He/She/It is... isn't he/she/it? She's coming, isn't she?
was/were... wasn't/weren't? It was fun, wasn't it?
has/have... hasn't/haven't? They've finished, haven't they?
will... won't? You will come, won't you?
can... can't? She can swim, can't she?
do/does... don't/doesn't? You like it, don't you?
did... didn't? He called, didn't he?
