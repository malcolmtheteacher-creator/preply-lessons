DESIGN SYSTEM COMPLIANCE
================================================================================

Header: linear-gradient(135deg, #667eea 0%, #764ba2 100%), white text
Font: "Segoe UI", Tahoma, Geneva, Verdana, sans-serif
Timer: 5 minutes (300 seconds), click-to-start ONLY (never auto-start)
Tab styling: border-bottom active state, #764ba2 color for active text

Content blocks: background #f8f9fa, border-left 5px solid #667eea
h2 color: #764ba2
Vocab cards: 8 cards per lesson, flipped gradient background on reveal
Answer buttons: background #667eea, hover #764ba2
Matching exercises: Two-column grid layout
Checklists: Interactive checkboxes with accent color #667eea

Key Features:
- NO pedagogical labels (TEEP, "I Do", "We Do", "Cold call", etc.)
- NO teacher notes or "Malcolm" references
- 1-to-1 student-teacher framing throughout
- Content-descriptive tab names (not "Lead-in" or "Language Focus")
- Each file 15-35KB (all within range)
- B1 vocabulary: intermediate level with real-world relevance
- Double quotes for JS strings containing apostrophes ("Time's up!", "don't", etc.)

INTERACTIVE ELEMENTS
================================================================================

1. Flashcard Vocabulary
   - Click to flip between word and definition
   - 8 cards per lesson, thematic to topic
   - Gradient background on flip state

2. Timers
   - 5 minutes (300 seconds)
   - Click-to-start button (never auto-starts)
   - Color changes: yellow at 30s remaining, red at 10s
   - "Time's up!" message when complete
   - Reset button to restart

3. Tabs
   - 4 tabs per lesson
   - Content-descriptive names
   - Smooth transitions
   - Active state styling

4. Interactive Exercises
   - Matching exercises (left/right columns)
   - Discussion prompts with "Show my thoughts" reveals
   - Comprehension questions with answer reveals
   - Checklists for task tracking
   - Dilemma scenarios with discussion points
