📚 The Dominic System Explained

🏆 Created by the GOAT of Memory Sports

Dominic O'Brien is the most decorated memory athlete in history:

• 8x World Memory Champion (1991-2001)

• Guinness World Record: Memorized 54 decks of cards (2,808 cards) in sequence

• Author of "You Can Have an Amazing Memory" - the bible of memory training

🎯 What is the Dominic System?

Created by Dominic O'Brien, this system converts number pairs into PEOPLE and ACTIONS.

  • Each number pair (00-99) = one specific person
  • You assign each person an action
  • Much easier to remember famous people than abstract words!
  • Great for competing in memory championships

🔤 Dominic Letter Code

Each digit becomes a letter based on its shape or sound:

💡 How It Works Step-by-Step

Example: Number 42 → Letters D-B

D = David, B = Beckham = DAVID BECKHAM

You picture David Beckham and assign him an ACTION (e.g., scoring a goal)

Key Advantage: Famous people are MUCH more memorable than random words!

🔍 Dominic vs Major System

📊 Head-to-Head Comparison

🔐 Major System

  • Uses consonant words
  • Must create vowels
  • More universal
  • Words sometimes random

👤 Dominic System

  • Uses famous people
  • Assigns actions
  • More memorable
  • Personal & emotional

🎯 When to Use Each System

Use Major System when:

  • You need quick, flexible word creation
  • The language isn't English
  • You're just learning memory

Use Dominic System when:

  • You want MAXIMUM memorability
  • You have time to build a personal list
  • You're competing in memory championships
